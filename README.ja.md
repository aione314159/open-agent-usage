# Open Agent Usage

AI コーディングエージェントの利用枠がどれだけ残っているかをメニューバーに表示する macOS 常駐アプリです。対応サービスは **Claude Code**、**Codex**、**Gemini**、**Antigravity** の 4 つです。

![メニューバー、折りたたみ状態](docs/menubar-strip.png)

普段はこのように表示されます。メニューバーの小さな帯に、サービスごとのアイコンとパーセンテージが並ぶだけです。

## 主な機能

- **4 つのエージェントを一つの帯で** — Claude Code、Codex、Gemini、Antigravity の利用枠を並べて表示するので、確認のために 4 つのアプリを開き直す必要がありません。
- **セッションをクリックしてすぐ切り替え** — パネルには最近の Claude Code セッションがプロジェクト・ブランチ・モデル・作業内容つきで並び、クリックするとそのウィンドウにそのまま切り替わります。（Pro）
- **データは Mac の外に出ません** — 使用状況はすでに Mac 上にあるファイルから読み取るだけで、どこにもアップロードしません。唯一の例外は、Pro ライセンスを有効化するときに一度だけ行われる Gumroad との通信です。
- **ライト／ダーク、自動でも固定でも** — 帯とパネルは通常 macOS の外観設定に従いますが、設定画面から Light または Dark に固定することもできます。
- **4 言語対応** — 英語・繁体字中国語・日本語・韓国語を、再起動なしで即座に切り替えられます。

## 展開パネル

メニューバーのアイコンをクリックすると、フルパネルが開きます。

![展開パネルと番号つき説明](docs/panel-annotated.png)

これらのスクリーンショットに写っているプロジェクト名、ターミナルのコマンド、アカウントのメールアドレスは、プライバシー保護のため意図的にぼかしています。画像が壊れているわけではありません。

1. **利用枠の帯** — すべての上限を横一列に表示：Claude Code の 5 時間枠と 7 日枠、Codex の使用量。それぞれに独自のパーセンテージとリセットまでの時間が表示されます。同じ行の右端にはライト／ダーク切り替えと設定ボタンがあります。
2. **セッション一覧** — 最近の Claude Code セッションを、プロジェクト・ブランチ・モデル・アイドル時間・現在の作業内容とともに表示します。クリックするとそのウィンドウに切り替わります。緑の点はそのセッションが現在実行中であることを示します。
3. **サービスごとのカード** — 各エージェントのログイン中のアカウント、プラン、モデルを表示します。
4. **上限ごとに 1 行** — リング、パーセンテージ、バー、リセット時刻。色は常に使用率に連動します：30% 以下は緑、60% 以下は青、80% 以下はオレンジ、80% 超は赤です。

![パネルのダーク表示とライト表示](docs/panel-light-dark.png)

同じパネルのダーク表示（左）とライト表示（右）です。

## インストール

1. [Releases](../../releases/latest) から最新の `.dmg`（または `.zip`）をダウンロードします。
2. ディスクイメージを開き、**Open Agent Usage** を **Applications** フォルダにドラッグします。
3. このビルドは**まだ Apple の公証（notarization）を受けていません**。そのため、初回起動時に macOS の Gatekeeper にブロックされます。開き方は以下をご覧ください。

これはプレビュー版です。公証済みビルドは今後のリリースで提供予定ですが、それまでは以下のいずれかの手順で開く必要があります。

### 未公証アプリの開き方（推奨方法）

Finder で Applications フォルダ内のアプリを **control キーを押しながらクリック**し、**「開く」**を選択、表示されたダイアログでもう一度**「開く」**をクリックします。この操作は最初の 1 回だけ必要で、以降は通常どおり開けます。

### 代替方法：ターミナル

```bash
xattr -dr com.apple.quarantine /Applications/OpenAgentUsage.app
```

## 追加設定

### Claude Code の利用状況にはブリッジスクリプトが必要です

Claude Code は利用状況のデータをステータスラインの標準入力（stdin）に渡すだけで、ファイルには保存しません。Open Agent Usage がこのデータを読み取るには、小さなブリッジスクリプトのインストールが必要です。

```bash
/Applications/OpenAgentUsage.app/Contents/Resources/scripts/install-claude-bridge.sh
```

スクリプトは変更前に `~/.claude/settings.json` を自動でバックアップします。既存のステータスラインはそのまま動作し、見た目も変わりません。

- インストール状況の確認：`--status` を付けて実行
- ブリッジを削除して元の設定に戻す：`--uninstall` を付けて実行

### Gemini の利用状況には「アクセシビリティ」権限が必要です

**システム設定 → プライバシーとセキュリティ → アクセシビリティ** を開き、**Open Agent Usage** を有効にします。

Gemini アプリが起動していない場合、パネル内の Gemini の行は自動的に非表示になります。

## 設定画面：ページごとの説明

### General

![設定 — General](docs/settings-general.png)

**Launch at login** はアプリをログイン項目として登録し、再起動後もメニューバーの帯が表示されるようにします。**Refresh interval** は 60 秒固定です。帯は実際に見たときだけ再描画されるため、これより頻繁に読み取っても得られるものはありません。**Updates** にはインストール済みのバージョンが表示され、**Check now** ボタンで GitHub の Releases ページと照合します。アプリが自動で何かをインストールすることはありません。

### Appearance

![設定 — Appearance](docs/settings-appearance.png)

**Language** は即座に反映され、再起動は不要です。**Theme** は通常 macOS に従いますが、**Light** または **Dark** に固定することもできます。**Text size**（Small／Medium／Large）は、帯とこの設定ウィンドウの両方を同時に拡大縮小します。

![設定 — Appearance、アクセントカラー一覧](docs/settings-appearance-accents.png)

同じページを下にスクロールすると、**11 種類のアクセントカラー**が並んでいます。Ocean Blue、Findmo Green から Cherry Blossom、Lavender、Coral、Mint、Amber、Burgundy、Graphite、Warm Brown まで。アクセントカラーは選択状態、ボタン、設定アイコンに使われます。

### Dynamic Island

![設定 — Dynamic Island](docs/settings-island.png)

**Show quota on the notch** は内蔵ディスプレイのノッチにつながる利用枠の帯を表示し、ノッチが横に広がったように見えます。クリックすると詳細が確認できます。**Expand on hover** はクリックだけでなくホバーでも詳細を開くようにします。既定ではオフです。ポインタがノッチを通るたびにシートが開くのは誤操作しやすいためです。**Show time until reset** は各パーセンテージの後にリセットまでの残り時間を追加します。例：`51% 1h59m`。

![設定 — Dynamic Island、展開時のオプション](docs/settings-island-expanded.png)

同じページを下にスクロールすると、**When expanded** の項目でフルパネルの表示内容を制御できます。**List sessions**（最近の Claude Code セッションと作業内容を一覧表示し、クリックでそのウィンドウに切り替え）、**Show per-service detail**（サービスごとに 1 枚のカードを表示し、各上限に固有のリング・バー・リセット時刻を表示）、**Show account and model**（各サービスカードにログイン中のメールアドレスと使用中のモデルを表示。録画や画面共有中はオフにしておくとよいでしょう）。

### Shortcut

![設定 — Shortcut](docs/settings-shortcut.png)

**Enable shortcut** をオンにすると、ポインタをノッチまで移動させなくても、どこからでも展開パネルを開閉できるグローバルショートカットが有効になります。キーの組み合わせボタンをクリックしてから、使いたいキーを押します。Escape でキャンセルでき、**Reset** で既定値に戻せます。このショートカットは Carbon 経由で登録されるため、アクセシビリティ権限は不要です。インストール直後から動作します。

### Permissions

![設定 — Permissions](docs/settings-permissions.png)

**Accessibility** はセッションが動作しているウィンドウを前面に表示するため、また Gemini の利用状況ページを読み取るために必要です。この行をクリックするとシステム設定が開きます。**Input monitoring** は展開パネルを Escape で閉じるために必要で、Accessibility とは別に許可が必要です。こちらはウィンドウを操作するのではなく、キーボード入力を監視するためのものです。**Claude statusline bridge** はブリッジスクリプトがインストールされているかどうかを表示し、クリックするとインストールコマンドをコピーできます。アクセシビリティ権限はアプリのコード署名に紐づいているため、未署名のビルドは再ビルドのたびに権限を失います。セッションの行が反応しなくなったときは、まずこのページを確認してください。

### Purchase

![設定 — Purchase](docs/settings-purchase.png)

ページ上部には現在のライセンス状態が表示され、試用期間中は残り日数も確認できます。その下の **Free and Pro** の表には、どの機能が無料（利用枠の帯）で、どの機能が Pro 限定（セッション一覧、および `open-agent-usage` コマンドラインインターフェース）かが一覧になっています。試用期間が終わると、Pro と表示された項目のみが利用できなくなります。

![設定 — Purchase、購入と有効化](docs/settings-purchase-buy.png)

同じページを下にスクロールすると、価格（**US$4.99**）と **Buy on Gumroad** ボタン、そしてライセンスキーを貼り付けて有効化する入力欄が表示されます。

### About

![設定 — About](docs/settings-about.png)

バージョン番号、ライセンス（**Proprietary**）、動作環境（**macOS 15.0+**）、データに関する表記（**Read locally only**、ローカルでのみ読み取り）、開発者名、コピー用ボタンつきのフィードバック用メールアドレスが表示されます。
